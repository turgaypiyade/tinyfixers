public static class Checks {
 static int count;static void Check(bool ok,string reason){count++;if(!ok)throw new Exception(reason);}
 static Spawner Make(State s)=>new Spawner{board=new BoardController{ObstacleStateService=s},resolvedLevel=s.level};
 public static void Run(bool before){
  var s=new State();s.Cover();var p=Make(s);
  // DrawStampedBeneathVisuals temporarily changes the shared level array identity, not the cover HP.
  s.level.obstacles[4]=(int)ObstacleId.PaintCanBox;
  var image=p.Attach();var v=image.GetComponent<PaintCanBoxView>();
  if(before){Check(v.Visible==1,"Legacy attachment must reproduce one visible can from cover HP");s.Expose(9);p.Hit(image,8);Check(v.Visible==8&&v.BuildCalls==2,"Legacy first hit rebuilds/increases one can into eight");Console.WriteLine("REPRODUCED: Grass HP 1 -> one visible can; first paint hit -> eight visible cans and a nine-child rebuild.");return;}
  Check(v.Visible==9,"A fresh covered paint box must start with all nine cans");Check(v.SlotCount==9&&v.BuildCalls==1,"One nine-slot pyramid is constructed");
  Check(s.remainingHitsByOrigin[4]==1,"Drawing doesn't mutate the cover's gameplay HP");
  int remaining;Check(s.TryGetLayerRemainingHitsAt(1,1,ObstacleId.PaintCanBox,4,out remaining)&&remaining==9,"Saved paint HP wins over temporarily stamped primary identity");
  s.level.obstacles[4]=(int)ObstacleId.Grass;Check(s.TryGetLayerRemainingHitsAt(1,1,ObstacleId.PaintCanBox,4,out remaining)&&remaining==9,"Opaque or see-through cover doesn't change the paint count");
  s.Expose(9);p.Hit(image,8);Check(v.Visible==8&&v.Drops==1,"First actual normal hit removes exactly one can");Check(v.BuildCalls==1,"Revealing/first hit reuses the existing pyramid");
  p.Hit(image,6);Check(v.Visible==6&&v.Drops==3&&v.BuildCalls==1,"Special hit removes two cans without reconstruction");
  p.Hit(image,0);Check(v.Visible==0&&v.Drops==9&&v.BuildCalls==1,"Finale hides exactly the remaining cans");
  foreach(int saved in new[]{1,3,5,8,9}){
   s=new State();s.Cover(saved);p=Make(s);s.level.obstacles[4]=(int)ObstacleId.PaintCanBox;image=p.Attach();v=image.GetComponent<PaintCanBoxView>();
   Check(v.Visible==saved,"Snapshot/previously damaged buried paint keeps its actual count");s.Expose(saved);p.Hit(image,Math.Max(0,saved-1));Check(v.Visible==saved-1&&v.BuildCalls==1,"Damaged reveal doesn't refill or rebuild on the next hit");
  }
  s=new State();s.Cover(7);s._stampedBeneathByCell[4].Add(new State.StampedBeneath(ObstacleId.Other,4,4,2));
  s._stampedBeneathByCell[4].Add(new State.StampedBeneath(ObstacleId.PaintCanBox,0,4,3));
  Check(s.TryGetLayerRemainingHitsAt(1,1,ObstacleId.PaintCanBox,4,out remaining)&&remaining==7,"Nested layers are selected by both type and origin");
  Check(!s.TryGetLayerRemainingHitsAt(1,1,ObstacleId.PaintCanBox,8,out remaining),"Wrong paint origin doesn't borrow another layer's count");
  Check(!s.TryGetLayerRemainingHitsAt(-1,1,ObstacleId.PaintCanBox,4,out remaining),"Invalid cell is safe");
  Check(!s.TryGetLayerRemainingHitsAt(1,1,ObstacleId.None,4,out remaining)&&!s.TryGetLayerRemainingHitsAt(1,1,ObstacleId.PaintCanBox,-1,out remaining),"Missing layer/invalid origin is safe");
  s=new State();s.Expose(4);p=Make(s);image=p.Attach();Check(image.GetComponent<PaintCanBoxView>().Visible==4,"Uncovered box uses live remaining HP");
  s.Expose(0);image=p.Attach();Check(image.GetComponent<PaintCanBoxView>().Visible==0,"An exhausted known layer never resurrects a full pyramid");
  p=new Spawner();image=p.Attach();Check(image.GetComponent<PaintCanBoxView>().Visible==9,"Missing state defaults to a fresh full box");
  Console.WriteLine("PASS: "+count+" production-method checks; fresh covered/revealed box 9 -> 8 -> 6 -> 0, no extra pyramid build, partial snapshots preserved.");
 }
