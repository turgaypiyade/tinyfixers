# Level isimleri — 1–188

Tek kaynak: [LevelNames.json](../../Assets/_Project/Resources/LevelNames.json). 61 mevcut tasarım ismi korundu, 119 isimsiz levele mevcut hedef/engel ve board kayıtlarına göre isim verildi.
